# Food Waste Reduction Analytics Dashboard

## Overview
This project analyzes restaurant food waste patterns and predicts food demand using Streamlit and Python.

## Features
- KPI Dashboard
- Waste Analysis
- Demand Prediction
- Inventory Optimization
- Interactive Visualizations

## Technologies Used
- Python
- Streamlit
- Pandas
- Plotly

## Run Project

```bash
streamlit run app.py
